# 紫外可见吸收光谱仪搭建与一维势阱检验 —— 报告一键生成

把光谱仪导出的原始 txt 变成一份符合课程 2026 模板的 Word 实验报告：
自动标定、算吸光度、基线校正、寻峰、拟合 Beer–Lambert、跑一维势箱模型，
最后生成带封面、公式、插图的 `.docx`。

## 启动

双击 `启动.vbs`（后台启动、没有黑框；会自动找 Python，缺依赖时弹一个窗口装好，
也可以先双击根目录的 `安装依赖.cmd`），浏览器会打开
<http://127.0.0.1:8791>。要停止请双击根目录的 `停止服务.vbs`，或在入口页点「停止全部服务」。

也可以直接：

```bash
python run.py                 # 起网页界面
python run.py --port 8792     # 换端口
python run.py --no-browser    # 不自动开浏览器
python run.py --test          # 无界面自检，生成一份报告
```

从统一入口（`物化实验报告工具`）进也可以，入口会自动拉起本模块。

## 选数据文件夹

界面上数据目录一行有「选择文件夹…」按钮：点了会弹系统的文件夹选择窗口，
选完自动填进输入框（再点「扫描」确认文件齐全）。也可以直接把路径粘进输入框。
溶解热 / 燃烧热两个工具的同一位置也加了同样的按钮。

## 数据从哪来

光谱仪软件（CCD 控制软件）导出的 txt，四列制表符分隔：

```
index   original   background   difference
```

`difference = original - background`，工具一律用 `difference` 当光强。

数据目录的默认结构（`数据/`）：

```
数据/
├─ 2026-10-14 & 17-01-51-氘灯.txt        第一周长波标定
├─ 2026-10-14 & 17-05-15-A4-3.txt        A4 样品（3 μmol/L）
├─ 2026-10-14 & 17-11-53-A4-乙醇.txt     A4 的乙醇空白
├─ 2026-10-21 & 13-36-23-1到3的校准.txt  第二周长波标定
├─ 2/ …                                  A3 浓度系列（0.5~50 μmol/L）+ 空白
├─ 3/ …                                  A3 双光源对比、A2
└─ 4/ …                                  第二周短波标定、A1、B1、B2、乙醇空白
```

文件路径与用途登记在 `pcal/uv.py` 的 `CALIBRATIONS` / `SAMPLES` 里；
换一批数据时改这两个表即可。

## 计算链

1. **标定**：在氘灯谱图上找 485.82 / 581.39 / 656.06 nm 三条特征峰 →
   线性拟合 `λ = a·pixel + b`。先在 `prior` 给出的系数附近 ±45 像素内寻峰，
   避免挑错峰；偏差过大时退回先验系数。
2. **吸光度**：`A(λ) = lg(I₀/I)`。
3. **平滑**：移动平均（默认 9 点）。
4. **基线校正**：在吸收带两侧各取一个窗口的中位吸光度，连成直线扣掉。
5. **Voigt 分峰**：吸收带用 1~2 个 Voigt 组元 + 低阶基线作非线性最小二乘拟合，
   取**总拟合曲线**的极大值作为 `λmax` 与 `A`（峰位比直接取噪声尖峰稳）。
   界面「处理参数 → Voigt 分峰组元数」可选自动 / 1 / 2。
6. **摩尔消光系数**：`ε = A/(c·b)`，`b = 1.00 cm`。
7. **Beer–Lambert 拟合**：图 7 画出全部浓度点，实线只拟合 0.5~10 μmol·L⁻¹
   的线性区，虚线是它的延长线；20/50 μmol·L⁻¹ 已饱和，画成空心点、不参与拟合。
   线性区用浅色底标出，图例放在右下角空白处（早先压在线上的版本被用户指出）。
8. **一维势箱**：`λ = 3297.8·L²/(2n+1)`，A 组用 A1、A4 解 `x, y` 再预测 A2、A3；
   B 组用经验箱长外推。

## 测量选择（同一浓度/分子测了多次时）

网页左侧有「测量选择」模块：浓度系列 0.5/1/5/10/20/50 μmol·L⁻¹ 各一个下拉框、
A1~A2~B2 各一个下拉框，列出该槽位的全部候选测量（文件名 + 峰位），
点「全部取最后一次」可一键把每个槽位设为最后测的那一条。
Beer 拟合用哪几个浓度也在下面勾选（默认 0.5~10）。

默认值（用户 2026-10-21 定）：第二天凡是测了多次的，一律取最后一次——
A3 5 → A3c5b、A3 20 → A3c20b、A3 50 → A3c50b、A2 → A2b、B1 → B1c。
选项保存在 `settings.json` 的 `conc_pick` / `molecule_default` / `beer_concs`。

## 杂散光与 Beer 定量（重要）

2026-10-21 的 A3 浓度系列里，样品透射光在 655 nm 附近有一个约相当于入射光强 20% 的
本底（遮光不严导致的漏光，也可能含样品荧光），把高浓度处的吸光度压平：
A(5)=0.247、A(10)=0.478、A(20)=0.580、A(50)=0.711。

> ⚠️ 曾经的做法是按 `A = lg((1−f)I₀/(I−fI₀))` 逐点扣掉 1/3 的杂散光。但那个 f 是从
> 个别点反推的，在高浓度处（T 接近 f）扣除结果对微小误差极其敏感——10 μmol/L 会被
> 放大到 1.19，而 20/50 μmol/L 直接无解；把「扣过的点」和「没扣的点」画在同一张
> A–c 图上，就会出现「10 μmol/L 比 20 μmol/L 还高」这种物理上不可能的结果
> （用户 2026-10-21 当场指出）。

因此现在的口径是：**全部使用实测吸光度**（基线校正 + Voigt 分峰，不扣杂散光），
`stray_mode` 默认 `off`。Beer 图里 6 个点统一是实测值、单调递增，
线性区 0.5~10 μmol/L 拟合得 A = (0.0433 ± 0.0011)c + (0.041 ± 0.006)，R² = 0.9988，
ε = (4.33 ± 0.11)×10⁴ L·mol⁻¹·cm⁻¹。由于杂散光会把 A 压低，这个 ε 只能算**下限**，
报告摘要、3.3 节和 4.1.1 节都写明了这一点。

界面上的「杂散光校正」选项保留，供检查不同假定下的影响，但默认关闭。

## 接入高斯计算（TD-DFT）

界面右侧新增 **「高斯计算（TD-DFT）」** 卡片，需要同级的
[高斯计算工具](https://github.com/ZhangRuijie66/Chemdraw-To-Gaussian)（`…/物理化学实验/高斯计算工具/`）：

| 按钮 | 作用 |
| --- | --- |
| 打开高斯计算工具 | 新标签页打开 `http://127.0.0.1:8795/`；没在运行会自动拉起 |
| 读取计算结果 | 读 `…\calculation\gjf\logs\` 下**所有含激发态的 `.log`**（也可手填日志目录），按「分子 / 泛函 / 几何版本」列出计算 λmax、f、S1；点行看计算 UV-Vis 谱 |

读到结果后点「一键生成报告」，**3.5 节会自动插入对照表**：

| 分子 | 计算 λmax / nm | 振子强度 f | S1 / nm | 实验 λmax / nm | Δλ / nm |
| --- | --- | --- | --- | --- | --- |

- 同一分子有多份结果时，先按几何版本（v2 优先）和泛函数目挑一组，组内取 PBE0；主表每个分子一行；
- 计算值取**振子强度最大**的允许跃迁（S1 可能是对称性禁阻的暗态）；
- 实验值自动从第 3 节结果里取，Δλ = 计算 − 实验；
- **A2 另有多泛函小表**（PBE0 / CAM-B3LYP / M06-2X / LC-wPBE），误差段按实际数据生成；
- 路径可在 `settings.json` 里配 `gcalc_dir` / `gcalc_logs_dir`（留空自动推断）。

> 说明：TD-DFT（PBE0/def2-TZVP）对花青类染料会系统性高估能隙（链越长误差越大），
> 换泛函/长程校正也救不回来（见 3.5 节与文献 [7]）；定量需 CC2/ADC(2)/CIS(D)/GW-BSE
> 或双杂化方法，本报告只把它用于趋势对照。
