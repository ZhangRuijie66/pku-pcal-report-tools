# 稀溶液法偶极矩 · 实验报告生成器

北京大学物理化学实验「稀溶液法测定极性分子的偶极矩」的报告生成工具，
与燃烧热 / 溶解热 / 蒸气压等工具同一套架构（原始数据 → 计算内核 → 本地网页 → Word 报告）。

## 实验

正丁醇（极性溶质）+ 环己烷（非极性溶剂）配 5 个浓度点（x ≈ 0.05~0.15），分别测：

- **电容**：PCM-1 精密电容测量仪，桥法；C′空 / C′环 / C′样 各平行两次；
- **密度**：DE45 型数字密度计（另用比重瓶对比测正丁醇密度）；
- **折射率**：阿贝折射仪测正丁醇。

## 处理链（与数据处理表及 2025 年参考报告一致）

```
x   = (m₁/M₂) / [(m₁/M₂) + (m₂−m₁)/M₁]          M₁=84.159、M₂=74.121（手册值，视为常数）
ε_环 = 2.023 − 0.0016·(T/K − 293)
C₀   = (C′环 − C′空)/(ε_环 − 1)，C_分 = C′空 − C₀
ε    = (C′样 − C_分)/C₀
ε = a·x + ε₁，ρ = b·x + ρ₁                       ← 两条 OLS 拟合（参数标准误）
A = (ε₁−1)/(ε₁+2)/ρ₁，B = M₁/ρ₁，C = 3M₁/((ε₁+2)²ρ₁)
P̄₂^∞ = A·(M₂ − bB) + aC                          ← Hedestrand 外推（cm³·mol⁻¹）
R = (n²−1)/(n²+2)·M₂/ρ₂                          ← 摩尔折射度（电子极化度）
μ/D = 12.81·√[(P̄₂^∞ − R)·T]                      （P、R 以 m³·mol⁻¹ 计）
```

不确定度：拟合参数用 OLS 标准误；σ_n、σ_ρ₂ 取假设值（界面可改）；
全部结果按「不确定度 2 位有效数字、末位对齐」排版。
报告另含三组**数据驱动的误差讨论**：

1. **表 6 置零归因**：把 a、ε₁、b、ρ₁ 的不确定度逐个置零重算 σ_P，定位主要贡献者（斜率 a）；
2. **电容误差假设**：设 σ_C′ = 0.01 pF，算出 σ_ε → σ_a → σ_μ ≈ 0.062 D（约为实测两倍），
   并反估本次电容测量精度 ≈ 0.005 pF；
3. **温度 / 原子极化度假设检验**：σ_T = 1 ℃ 与 P_A ≈ 1% 都不是主要误差来源。

## 数据导入
