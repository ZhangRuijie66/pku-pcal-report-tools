# 电导率工具（电解质溶液电导率的测定）

从手记读数出发（电导率仪无数据导出），一键生成《电解质溶液电导率的测定》
实验报告（与课程 2026 模板同款排版的 Word 文档）。

## 实验内容（讲义 实验七）

1. KCl 标准溶液标定电导池常数，测去离子水 κ_w；
2. 测 4 种溶液（NaNO₃ / NaAc / HNO₃ / HAc，各 5 个浓度）的电导率，
   κ_校 = κ_测 − κ_w，Λ_m = κ_校/c；
3. 强电解质按 Kohlrausch 经验公式 Λ_m = Λ_m∞ − B√c 线性拟合，外推 Λ_m∞；
4. 离子独立运动定律组合得 Λ_m∞(HAc)（加 NaAc + HNO₃、减 NaNO₃），
   与 CRC 文献值比较求相对误差；
5. 弱电解质两种方法求标准电离平衡常数：求平均法（逐瓶 α、K°，
   偏导传播不确定度）与拟合直线法（(c/c°)Λ_m–1/Λm 拟合），
   与文献 pKa = 4.756 比较。

## 用法

- 双击 `启动.vbs`（无黑框），或 `python run.py`；
- `python run.py --test` 无界面自检，报告写入 `..\实验报告输出\自检报告（电导率）\`；
- 界面左栏：数据目录 + 封面字段；右栏：KPI、标定与测量数据编辑表、
  图 2~图 6 预览、关键结果；
- 「保存测量数据」写入 `<数据目录>\电导率数据.json`（首次运行自动落一份
  2025 参照数据的默认值）；「一键生成报告」输出到
  `..\实验报告输出\<学号>-<姓名>-电导率\`（docx + figures）。

## 数据格式

电导率仪（DDSJ-307F）没有数据导出，读数手记。`电导率数据.json` 里：

- 电导率以 **S·m⁻¹ 字符串**存储（如 `"0.01575"`）——末位不确定度规则
  「最后一位取 2」依赖小数位数，浮点会丢掉末尾的 0；
- 浓度以 mol·m⁻³ 字符串存储（4 位有效数字）；
- `combo` 字段描述 Λm∞(HAc) 的组合方式（加/减哪些强电解质），
  换电解质体系（如讲义版本的 NaCl/HCl）时改这里和 solutions 键名。

## 判据与口径

- 读数末位不确定度：σ = 2×10^(−小数位数) S·m⁻¹（参考报告口径，
  1 号 HAc 溶液 0.0258 → 0.0002，其余 → 0.00002）；
- 拟合不确定度 = 截距/斜率的 OLS 标准误（σ√(1/n+x̄²/Sxx) 等）；
- K° 求平均法的合成不确定度 = √(Σσᵢ²)/5（参考报告式）；
- 文献值：离子 Λm∞ 与 pKa(HAc) = 4.756 来自 CRC Handbook^{[2]}。

用 2025 年参照数据（`物理化学实验\物理化学实验\电导率\`）验证：
Λm∞(NaNO₃) = (0.01214±0.00020)、NaAc (0.00912±0.00010)、
HNO₃ (0.04286±0.00072) S·m²·mol⁻¹（参考 0.01216/0.00911/0.04286）；
Λm∞(HAc) = (0.03983±0.00075)（参考 0.03981）；
K° 求平均法 (1.434±0.026)×10⁻⁵（参考 1.436）、拟合直线法
(1.787±0.069)×10⁻⁵、r = 0.99991（参考 1.789，差异来自参照者中间值舍入）。
