# 溶液表面吸附的测定 · 报告生成器

最大气泡压力法 + 吊片法测正丁醇水溶液的表面张力，按 Gibbs 吸附公式求饱和吸附量
`Γ∞`、分子面积 `q` 和浓度修正后的 `q_c`，一键生成与课程 2026 模板同款的 Word 报告。

## 启动

```bat
双击 启动.vbs
:: 或
python run.py
python run.py --port 8772 --no-browser   :: 不自动开浏览器
python run.py --test                     :: 用示例数据生成一份自检报告
```

默认端口 **8771**，也可以从统一入口 `物化实验报告工具/` 的卡片进入。

## 数据录入

左侧卡片可以：

- **手工填表**：零点、纯水、各浓度溶液的左右液柱高度；吊片法的 γ。
  「实验条件」里的**平行测定次数**可选 2~6 次（默认 3），表格列数随之改变。
- **导入 CSV/TXT**：
  - 最大气泡法：`c, 左×n, 右×n` —— 列数决定 n（7 列 = 3 次、11 列 = 5 次、
    也接受 4 列 `c,左,右,拟合` 与 3 列 `c,左,右`），导入后自动把平行次数改过去
  - 吊片法：`c, γ×n`
  - 零点/纯水：`左×3, 右×3`
- **载入示例数据**：2025 年同课程报告的数据，用于预览流程；正式报告请替换。
- **保存数据**：写入 `data/表面吸附数据.json`，下次启动自动读回。

作图横轴可选 **lg c（讲义口径）** 或 **ln c（旧报告口径）**；报告会自动改写公式。
压力计零点可选扣除（`Δh = h_right − h_left − Δh₀`）或不扣除（旧报告口径）。

## 平行测定次数（2026-10-28）

「实验条件」第一行的**平行测定次数**可选 2~6 次，默认 3 次：

- 零点、纯水、最大气泡法、吊片法四张表的列数同步变化（`h_l1…h_ln`、`h_r1…h_rn`、`γ1…γn`）；
- 计算内核本来就按实际个数算均值和标准误差，换 n 不需要改算法；
- 报告正文的「三次读数」「三次平均」会跟着改成「五次读数」等；
  零点各次读数不完全相同时，措辞自动改成「由 n 次读数的标准误差与仪器读数误差合成」；
- 导入 CSV 时按列数推断 n 并自动切换；
- 次数随「存为默认」写入 `settings.json`。

## 只读一侧液柱（2026-10-28）

压差计两臂等截面、管内液体总量恒定，故 `h_left + h_right = S` 为常数。
「实验条件」里把**液柱读数方式**改成「只读左侧」或「只读右侧」后：

- 表格里另一侧变灰、不用填（填进去也不会被当成实测值）；
- 另一侧按 `h_other = S − h_已测` 实时换算，边输边看；
- **两臂高度总和 S** 留空时自动估计（取已有两侧配对读数之和的中位数）；
  估不出来（数据里从来没两侧同时读数）时会标红提醒，此时必须手填；
- 切换读数方式时，会先把当前两侧数据综合出的 S 固化进输入框，切回来不丢；
  `S` 与读数方式随「存为默认」写入 `settings.json`，下次打开自动恢复；
- 不确定度相应放大——`Δh = S − 2h`，同一读数在 Δh 里用两次，
  `σ_Δh = √(4σ_h² + σ_S² + σ_Δh₀²)`（`σ_S` 按单次读数误差计）；
- 报告 3.1.1 会写明换算关系，并给出改写后的不确定度公式。

若选了「只读一侧」但数据里两侧都填了，按实测值算，界面上会提示一句。

## 计算

```
Δh = h_right − h_left − Δh₀
γ  = γ_w · Δh / Δh_w
γ = k·lg c + b  →  Γ∞ = −k / (2.303 R T)      （ln c 时分母为 R T）
q  = 1 / (Γ∞ N_A)
q_c = 10^18 / [Γ∞ N_A + 100 (c N_A)^(2/3)]
```

- 高浓度线性区的选点由表格里的「拟合」复选框控制；吊片法的离群点取消勾选即可排除。
- 不确定度：单次读数 `σ_h`（默认 0.02 cm）与三次平行的标准误差合成，再传播到 Δh、γ、
  斜率、Γ∞ 与 q；吊片法用三次读数的标准误差 + 仪器项。只读一侧时改用上节的
  `σ_Δh = √(4σ_h² + σ_S² + σ_Δh₀²)`。
- 结果卡显示 Γ∞、q、R²、拟合点数与两法差异；下方给出 q_c 与相对偏差。

## 导出数据表（2026-10-28）

左栏「数据」卡片里两个按钮：

- **导出数据表 .xlsx**：一个工作簿六个表——`说明` / `结果` / `最大气泡法` /
  `吊片法` / `零点与纯水` / `浓度修正`；表头加粗冻结、列宽自适应，
  Γ∞ 与 σ(Γ∞) 用科学计数格式；`最大气泡法` 末列「h_r 来源」标明该侧是实测还是按 S 换算。
- **导出 .csv**：单张长表，两种方法摊在同一组列里（吊片法的 h 列留空），
  UTF-8 BOM，Excel 双击打开不乱码，方便筛选、透视。

文件写在报告同目录：`实验报告输出/<学号>-<姓名>-表面吸附/<…>-数据.xlsx`。
同名文件直接覆盖（数据表是中间产物），只有正被 Excel 占用时才自动改名。
**导出数据表不会改写 `data/表面吸附数据.json`**（只有生成 Word 报告才回写）。

`实验报告输出/<学号>-<姓名>-表面吸附/` 下生成 docx 与 `figures/`。报告为完整版：

```
  3.2 吊片法（同上）
  3.3 两种方法的比较
4 结果与讨论（4.1 结果 / 4.2 讨论 / 4.3 结论）
参考文献
```
