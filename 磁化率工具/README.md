# 磁化率的测定 - 实验报告生成工具

## 功能

本工具用于生成《磁化率的测定》实验报告，采用古埃磁天平法测定固体物质的磁化率。

### 主要功能

- 自动处理实验数据（莫尔盐标定、样品磁化率计算）
- 计算摩尔磁化率、分子磁矩、未成对电子数
- 生成符合课程要求的 Word 格式实验报告
- 提供交互式网页界面进行数据查看和参数调整

## 使用方法

### 1. 启动工具

双击 `启动.vbs`（无黑框）或运行：

```bash
python run.py
```

### 2. 网页界面

启动后会自动打开浏览器，访问 `http://127.0.0.1:8781`。

界面与其它实验模块使用同一套模板：顶部是「返回入口 / 存为默认 / 重新计算 /
一键生成报告」，左侧是数据与封面/实验条件，右侧是结果摘要、样品表、对比图和计算明细。

### 3. 数据输入

- 点击「载入示例数据」使用内置的 2025 年参照数据；
- 或点击「导入 JSON 数据」上传自己的数据文件；
- 「保存数据」会把当前数据写回 `data/磁化率数据.json`，可随工具一起拷走；
- 右侧「对比图」可切换摩尔磁化率、分子磁矩、未成对电子数三张横向散点图；
  反磁性样品在 μ/n 图中以空心点记作 0。

### 4. 生成报告

填写封面信息后，点击顶栏「一键生成报告 (.docx)」。

报告输出位置：`../实验报告输出/<学号>-<姓名>-磁化率/`

## 计算原理

### 1. 莫尔盐标定

莫尔盐的比磁化率公式：

$$\chi_{\text{莫}} = \frac{9500 \times 10^{-9}}{T + 1} \times 4\pi \quad (\text{m}^3 \cdot \text{kg}^{-1})$$

### 2. 样品磁化率

$$\chi_{\text{样}} = \chi_{\text{标}} \cdot \frac{m_{\text{标}}}{m_{\text{样}}} \cdot \frac{\Delta m_{\text{样}} - \Delta m_{\text{空}}}{\Delta m_{\text{标}} - \Delta m_{\text{空}}}$$

### 3. 摩尔磁化率

$$\chi_m = \chi \cdot M \quad (\text{m}^3 \cdot \text{mol}^{-1})$$

### 4. 分子磁矩

$$\mu = 797.7 \sqrt{\chi_m \cdot T} \quad (\mu_B)$$

### 5. 未成对电子数

$$n = \sqrt{797.7^2 \cdot \chi_m \cdot T + 1} - 1$$

## 2026-11-04 修复毛重/净重口径 + 示例数据改为参照报告原始称量

**根本问题**：`process_all` 给标样传的是**净重**（`m_mohr_zero − m_tube_zero`）
与**净质量变化**（`Δm_mohr − Δm_tube`），`process_sample` 给样品传的却是**毛重**
（`m_zero`，含空管）和**未扣空管**的 `Δm`。两者进入同一个比值式
`χ_样 = χ_标·m_标·Δm_样/(Δm_标·m_样)` —— 分子净重、分母毛重。

用一个恒等式就能证明：如果样品与标样**完全相同**，算出的 χ_样 必须等于 χ_标。
修复前得到 0.3333 倍，正好等于 `m_标净/m_样毛 = 5/15`。

**后果**：CuSO₄·5H₂O（Cu²⁺ 是 d⁹，必有 1 个未成对电子）算出 μ = 1.03 μ_B、
n = 0.43 个未成对电子——半个电子，物理上不可能。

**修法**：`process_sample` 增加 `m_tube_zero` / `delta_m_tube` 两个参数，
`m_sample = m_zero − m_tube_zero`、`Δm_sample = Δm − Δm_tube`，与标样完全一致。

**顺带把 `sample_data` 换成参照报告表1 的真实称量**（原来的 18.23/24.57 是编造的，
内部还不自洽：标样 Δm=0.0212 与样品 Δm=0.0045 差 4.7 倍，真实实验里同电流下应同量级）。
现在 `magnetic.sample_data()` 取 `2300012602-李晨曦-磁化率.pdf` 表1 的 0–3.00 A 上行支：

| | 修复前 | 修复后 | 参照报告 |
| --- | --- | --- | --- |
| CuSO₄ χ_m | 5.63e-9 | **1.7977e-8** | 1.80e-8 |
| CuSO₄ μ | 1.029 | **1.8365** μ_B | 1.84 |
| CuSO₄ n | 0.435 | **1.091** | 1 |
| χ_莫 | 4.0243e-7 | **4.0352e-7** | 4.035e-7 |

**另一处**：反磁性样品（χ_m < 0）的 μ/n 原来被印成 `0`，正文写成「分子磁矩为
0 μ_B，未成对电子数约为 0」——把反磁性说成「磁矩为零的顺磁体」。现在
正文与摘要都改写为「为反磁性物质，无永久磁矩，未成对电子数为 0」。

测试里补了一条**物理判据断言**（Cu²⁺ 的 n 必须≈1、μ 必须≈√3），
以后这类口径错误会被测试直接拦住，而不是被「照当前输出写的基准」锁死。
