报告输出 / PDF 预览

生成 docx 后在这里点「预览 PDF」；首次用本机 Word 转换，约 10–30 秒（Word 启动）， 之后会复用同目录的 PDF。缺少 Word 时会给出提示，可直接用 Word 另存为 PDF。

怎么用

  1. 点卡片上的「启动这个模块」（首次约 2–4 秒，启动后会自动打开实验界面）； 已经在运行的模块直接点「进入实验界面」。
  2. 在实验界面里选好数据文件夹 → 核对取点 → 「一键生成报告 (.docx)」， 报告写到 实验报告输出\ 里（每份报告一个子文件夹， 全部实验共用这一个目录）。
  3. 回到本页可以随时切换实验；全部服务都在后台运行，没有命令行窗口， 要收摊就点右上角停止全部服务（或双击实验文件夹里的 停止服务.vbs）。
  4. 每个实验也能单独启动：进各自的工具目录双击 启动.vbs。

再加一个实验

  2. 让它的 server.main() 支持 --port / --no-browser。
  3. 在 portal.py 的 MODULES 里把 tool 从 None 改成目录名，入口页上这张卡片就自动变成可点。
