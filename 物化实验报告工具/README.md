# 物化实验报告工具 · 统一入口

一个入口页，选择要做哪个实验。一次启动本机已安装的全部实验模块，
点卡片就进对应实验的交互界面。

## 启动

双击 **`启动.cmd`**（或 `python run.py --no-browser`），浏览器会打开入口页
`http://127.0.0.1:8700`。

关闭这个命令行窗口 = 停止入口页和它拉起的全部模块。

## 它做了什么

```
物化实验报告工具/             ← 入口（本目录）
├─ 启动.cmd                 双击启动
├─ run.py                   入口脚本
├─ portal.py                入口服务：挑端口、拉起子进程、健康检查、退出时收摊
└─ web/index.html           卡片式入口页
```

- 只监听 `127.0.0.1`，不联网、不上传数据。
- 每个实验仍是**独立目录、独立进程**（各自的 `pcal` 包互不干扰），
  入口只负责把它们拉起来并做健康检查。
- 入口页每 15 s 刷新一次状态；卡片上的绿点表示该模块正在运行。
- 如果某个模块的端口上已经有服务（比如你自己双击过它的 `启动.cmd`），
  入口会直接复用，不会重复启动。

## 再加一个实验

1. 照 `燃烧热工具` / `溶解热工具` 的样子新建 `××工具\`：
   `pcal\`（计算内核 + `docxkit`/`omml` 排版）、`web\`（手写 SVG 界面）、
   `templates\`（报告模板）、`启动.cmd`（**内容必须全 ASCII**）、`run.py`。
2. 让它的 `server.main()` 支持 `--port N` / `--no-browser`
   （两个已有模块都支持，直接照抄那几行参数解析）。
3. 在 `portal.py` 的 `MODULES` 列表里把对应条目的 `tool` 从 `None`
   改成目录名、`port` 给一个独立端口。入口页上这张卡片就自动变成可点。

## 报告写到哪

**所有实验的报告集中在一处，而且在工具目录外面**——工具目录上一级的
`实验报告输出\`；每份报告再单独占一个子文件夹：

```
物理化学实验\实验报告输出\                 ← 全部实验共用这一个目录
├─ <学号>-<姓名>-<实验名>\
│   ├─ <学号>-<姓名>-<实验名>.docx
│   └─ figures\            该报告用到的插图
└─ 自检报告（<实验名>）\      run.py --test 的产物，可删
```

一份报告连图在一起，可以整体拷走/上交。输出位置在各自的
`pcal/server.py` 里（`OUT_DIR = os.path.dirname(ROOT)/实验报告输出`，一行）；
各实验界面上也会显示当前输出目录。本目录（入口）不参与计算，也不保存数据。

## 可移植版

`…\物理化学实验\发布\物化实验报告工具-可移植版.zip`（约 3 MB）：把入口页和
五个模块打成一个绿色包，解压到任意位置、双击根目录的 `启动.cmd` 即可用。
目标机器只要有 Python 3，启动器会自动装依赖（走清华源）。包内 `使用说明.md`。

打包命令（改完代码后重新发布时照这个跑）：用 `robocopy` 把五个工具目录
拷到 `发布\_stage\` 下（排除 `输出\`、`__pycache__\`、`settings.json`），
再 `Compress-Archive`。`settings.json` **不要进包**——里面是使用者自己的
姓名/学号/数据目录。根目录的 `启动.cmd` 靠“找哪个子目录里有 portal.py”
来定位入口，这样它自己可以保持纯 ASCII。
