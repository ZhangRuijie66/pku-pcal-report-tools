# 燃烧热实验报告 · 一键生成

北京大学物理化学实验「燃烧热的测定」模块的实验报告自动生成工具。
填写参数、在图上拖动一下雷诺校正的拟合区间、点一下按钮，就能得到一份
与课程报告模板同款的 Word 报告（公式是 Word 原生公式，可直接双击编辑）。

---

## 快速开始

双击 **`启动.vbs`**（或在命令行运行 `python run.py`），浏览器会自动打开
`http://127.0.0.1:8731`。服务在后台运行，没有命令行窗口；要停止请双击根目录的
**`停止服务.vbs`**，或在入口页点「停止全部服务」。

要求：Windows + Python 3.9 以上，依赖 `numpy scipy matplotlib python-docx`
（`启动.vbs` 会自动找 Python；缺依赖时自动弹一个窗口装完再后台启动，
也可以先双击根目录的 `安装依赖.cmd`）。程序完全在本机运行，不联网、不上传任何数据。

## 使用流程

1. **数据文件夹**：默认已指向 `…\物理化学实验\1 燃烧热`，里面放着课程软件
   导出的 `*combustiondata.csv`（或改名后的 `方糖.csv` 等）。按「扫描」重新读取。
2. **报告封面 / 实验条件**：填姓名、学号、组别、日期、大气压强，确认内筒水体积，
   室温按**摄氏度**填写。填好后点 **「存为默认」**，以后每次打开程序都会自动填回
   （保存在程序目录的 `settings.json`，点「恢复出厂默认」可清除）。
   - 室温留空 → 用数据文件里记录的 `room_temperature(K)`
   - 勾选「全部轮次统一用这个室温」→ 所有轮次都用你填的室温（数据文件里的值忽略）
   - 水的密度 / 比热容留空 → 按采用的那个室温自动查表（CRC Handbook，与课程软件同一套表）
3. **数据轮次**：每一轮选一个数据文件，指定角色
   - **标准物质（苯甲酸）**：用来标定量热计常数 *W*；
   - **待测样品**：用来算燃烧热，再选主成分（蔗糖 / 葡萄糖 / 果糖 / 自定义）。
     标准物质那一轮主成分是固定的苯甲酸，不需要选。
4. **雷诺校正**：右侧给出温差–时间曲线。程序按「自动寻点方式」自动推荐两段拟合区间；
   若不满意，可以
   - 直接在图上**拖动**橙色（拟合1）/ 绿色（拟合2）端点，或
   - 用「微调序号 + 数值 + 应用」精确输入数据点下标（重算后选择不会被重置）。
   每次改动都会立刻重算 ΔT 与全部结果。曲线下方会显示当前取点方式与四个端点
   的下标和时刻，方便核对。
5. **一键生成报告 (.docx)**：所有实验的报告集中写到**工具目录外面**的
   `…\物理化学实验\实验报告输出\`，并且**每份报告单独占一个子文件夹**
   `学号-姓名-燃烧热\`（缺项自动跳过），里面是
   - `学号-姓名-燃烧热.docx` —— 报告本身
   - `figures\` —— 报告里用到的 600 dpi 雷诺校正图

   一份报告连图在一起，可以整体拷走。目标文件正开在 Word 里时会自动改名写入
   `xxx (2).docx`，仍在同一个文件夹里。界面上会显示当前输出目录。

## 报告内容

**按课程 2026 模板排版**（`templates\燃烧热报告模板2026.docx`）：A4、四边 2.5 cm、
页眉「物理化学实验 / 实验题目」、页脚「页码 / 总页数」。

排版约定：**正文一律五号（10.5 pt）**、**单倍行距**、首行缩进 2 字符；
变量斜体、单位正体、说明性下标与化学式下标正体；只示出变量值的式子用普通文本，
只有真正做运算的式子才是 Word 原生公式（可双击编辑）。
**标题套 Word 的「标题 1/2/3」样式**（一级黑体、二级宋体+Arial、三级仿宋+Arial），
所以导出 PDF 时勾选"创建标签后使用书签"就能得到目录书签。

- **封面 + 摘要 + 关键词**：同处第 1 页。封面自动填入题目 / 姓名 / 学号 / 组别 /
  实验日期 / 室温 / 大气压强（题目同时写进页眉）；摘要根据计算结果自动撰写，
  含 *W* 与各样品 *Q*<sub>p</sub> 及其不确定度。
- **引言**：**另起一页，从第 2 页第一行开始**。实验目的、实验原理、实验方法
  三部分均由讲义[1]「实验一 燃烧热的测定」精简而来——包括
  Δ*U* = *Q*<sub>V</sub>、*Q*<sub>V</sub> = −*C*<sub>V</sub>Δ*T*、
  *Q*<sub>p</sub> = *Q*<sub>V</sub> + Δ*nRT*、燃烧热随温度的变化关系，
  以及量热计常数与样品恒容燃烧热的两个计算式。
  「实验方法」末尾插入讲义装置图（**图1** 氧弹式量热计与氧弹的构造，
  取自 `assets/装置图.png`，正文有"装置如图1所示"的引用）。
- **2 实验部分**：仪器试剂 + 每一轮的操作步骤与实验条件（按**真实实验轮次**排列）。
- **3 数据与结果**：表1 原始数据记录（真实轮次顺序）；随后是逐轮的雷诺校正图与
  两条拟合直线方程、量热计常数 *W* 的计算与不确定度、各样品的恒容 / 恒压燃烧热
  与不确定度；**小节顺序为「先标定、报告主角样品放最后」**（否则样品计算会引用
  还没标定出来的 *W*）。
- **4 结果与讨论**：**4.1 实验结果**（*W* + 各样品结果，按**本次实际测定的样品**逐个给出
  摩尔燃烧热、每克热值与文献偏差；混合物类样品只给 J·g⁻¹，不硬凑 mol；
  末尾附**一小段讨论**：与手册值的相对偏差、被忽略的误差、主要误差来源、*W* 对取点敏感）、
  **4.2 实验结论**（简写版不单列「实验讨论」一节）。
- **参考文献**（含数据处理算法的出处与许可）。

## 计算与不确定度

计算链路与课程软件 `Dissolution_Combustion v2.2.4` 完全一致：

| 量 | 公式 |
| --- | --- |
| 样品质量 | *m*<sub>sam</sub> = *m*<sub>tot</sub> − *m*<sub>cot</sub>（可燃物+棉线 − 棉线） |
| 苯甲酸恒容燃烧热 | *Q*<sub>V</sub> = *Q*<sub>p</sub> − Δ*nRT*/*M*<sub>r</sub>（Δ*n* = −0.5，*M*<sub>r</sub> = 122.123 g/mol） |
| 镍丝/棉线校正 | Σ*q*<sub>V</sub> = *Q*<sub>V-Ni</sub>*m*<sub>Ni</sub> + *Q*<sub>V-cot</sub>*m*<sub>cot</sub>（−3243 / −16736 J·g⁻¹） |
| 量热计常数 | *W* = (−*Q*<sub>V</sub>*G* − Σ*q*<sub>V</sub>)/Δ*T* − *DC*<sub>w</sub> |
| 样品恒容燃烧热 | *Q*<sub>V</sub> = [(*W* + *DC*<sub>w</sub>)Δ*T* + Σ*q*<sub>V</sub>]/*m*<sub>sam</sub> |
| 摩尔燃烧热 | *Q*<sub>p</sub> = *Q*<sub>V</sub>·*M*<sub>r</sub> |

不确定度按万分之一天平允差 *e* = 0.2 mg、温差仪允差 *e* = 0.002 K、
均匀分布取 1/√3、两次测量按 √2 合成：

* σ<sub>ΔT</sub> = 2*e*/√3 ≈ 0.0023 K
* σ<sub>*G*</sub> = σ<sub>*m*<sub>Ni</sub></sub> = √2*e*/√3，σ<sub>*m*<sub>cot</sub></sub> = *e*/√3
* σ<sub>Σ*q*<sub>V</sub></sub>、σ<sub>*W*</sub>、σ<sub>*Q*<sub>V</sub></sub> 按误差传播公式逐项合成（见报告正文）

## 雷诺校正算法

对点火前后两段平台区各作最小二乘直线拟合、把直线外延；用 B 样条平滑
拟合中间实测曲线；再解等面积方程
`½(k₂−k₁)t₀² + (b₂−b₁)t₀ − ∫ = 0`
使竖线 *t*₀ 左右两块面积相等，则 *T*<sub>l</sub> = *A*(*t*₀)、
*T*<sub>r</sub> = *B*(*t*₀)，Δ*T* = *T*<sub>r</sub> − *T*<sub>l</sub>。

自动推荐区间先复刻课程软件的阈值算法；若该算法因基线漂移给出不可用的区间
（等面积方程在数据范围内无解），会自动退化为基于一阶导数的稳健寻点
（主升温段 = 导数大于峰值 20 % 的区间，两侧各取平台）。

## 关于取点（雷诺校正区间）

程序有三种自动取点方案，界面右上「自动寻点方式」可切换，取点结果会打印在
曲线下方，也可以随时拖动橙色 / 绿色端点手动调整。

| 方案 | 说明 |
| --- | --- |
| **与课程软件一致**（默认） | 复刻软件的「滑动窗口标准差 &lt; σ」判据，取点与 `combustion.csv` 里记录的 Start/End 相同 |
| 升温段法 | 平台1 取升温前固定时长、平台2 取升温后固定时长；基线漂移大时更稳 |
| 平台锚点法 | 两段窗口都紧贴升温段，避免拖到指数拖尾深处 |

软件算法失效时（例如基线漂移被误判成平台结束，导致区间落在还在上升的曲线上、
等面积方程无解）会自动改用其它方案，并在界面上给出提示。

**σ 阈值很关键。** 课程软件内置 σ = 0.005，但对本套「升温缓慢、基线有漂移」的
数据，σ = 0.005 会把基线漂移误判成平台结束，把拟合区间放到正在上升的曲线上；
默认值改为 **0.02** 才能取到真正平直的两段平台：

| σ | 苯甲酸 ΔT | *W* / (J·K⁻¹) | 方糖 / 黄冰糖 *Q*<sub>p</sub> | 两样品一致性 |
| --- | --- | --- | --- | --- |
| 0.005（软件内置） | 1.416 | 3170.0 | 5486 / 5725 kJ·mol⁻¹ | 4.27 % |
| **0.02（本程序默认）** | 1.327 | 4225.5 | 5771 / 5771 kJ·mol⁻¹ | **0.01 %** |

把 σ 设回 0.005 时，程序算出的 *W* = 3170.0 J·K⁻¹ 与课程软件截图里的
*W* = 3170.0 J·K⁻¹ **完全一致**——这条链路是对的，只是对本套数据而言取到的平台
不够平。量热计常数 *W* 完全由苯甲酸的实测值标定，请自行核对哪个更符合本台仪器的预期。



## 换成自己的数据

1. 把课程软件导出的 `*combustiondata.csv` 放进任意文件夹；
2. 在界面上把这个文件夹路径填到「数据文件夹」并点「扫描」；
3. 在轮次卡片里选择对应文件、指定标准物质 / 待测样品即可。

csv 需要是课程软件（或本程序「数据记录」模式）导出的 UTF-8 格式：
前六行为 `room_temperature(K)`、`water_volume(mL)`、`cotton_mass(g)`、
`combustible_mass(g)`、`Nickel_before_mass(g)`、`Nickel_after_mass(g)`，
第七行表头 `time(s),Delta_T(K)`，其后每行 `时间,温差`。
