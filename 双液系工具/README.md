# 双液体系沸点-成分图 · 实验报告生成器

环己烷-乙醇双液系实验（实验四）的一键报告工具：原始数据 → 计算内核 →
网页界面 → Word 报告（2026 课程模板、Word 原生公式）。

## 启动

- 双击本目录 `启动.vbs`（无黑框，默认端口 8821），或
- 统一入口：双击上层目录 `启动入口.vbs`，点「双液体系沸点-成分图的绘制」卡片，或
- 命令行：`python run.py`（`--port` / `--no-browser` 可选）

`python run.py --test` 为无界面自检：用内置示例数据跑一遍两种口径的计算并生成
`实验报告输出\自检报告（双液系）\`。

## 数据与界面

数据存在 `data/双液系数据.json`，网页左侧直接编辑：

- **工作曲线滴瓶**：m₁（乙醇质量）、m₂（环己烷质量）、折射率 n；
  「剔除」勾选框把该点移出拟合。纯环己烷/纯乙醇两点是工作曲线在 x=0/1 的锚点，
  在「纯组分折射率」卡片里填写，与滴瓶合并编号 i = 0~8。
- **沸点测定**：V(乙醇)、V(环己烷)、n_g1/n_g2、n_l1/n_l2（平行读数）、T_b/℃、p₀/kPa。
- **处理选项**：组成变量（质量比 / 质量分数）、折射率读数误差 σ_n、
  文献恒沸点与恒沸组成（文献组成一律以乙醇质量分数填写）。
- 右侧实时预览工作曲线 / 剔除后曲线 / 相图，下方给出拟合参数、
  学生化残差、恒沸点与逐点反推结果。

「一键生成报告」输出到 `..\实验报告输出\<学号>-<姓名>-双液系\`（docx + figures）。

## 计算口径（重要）

- **组成变量默认为质量比 x = m₁/m₂（参照报告口径）**：本实验数据在质量比变量下
  二次拟合优度显著更高（R²≈0.9996 对质量分数口径的 ≈0.96），反推与误差传播也
  更稳定。可在界面切换为**质量分数 m₁/(m₁+m₂)**（讲义字面口径），报告会如实
  标注当前使用的定义。
- 工作曲线 n = Ax² + Bx + C；反推取 [0,1] 内的根
  x = (−B − √(B²−4A(C−n)))/(2A)；平行读数分别反推后取平均。
- 离群点：学生化残差 rᵢ = eᵢ/(s₋ᵢ√(1−hᵢᵢ))，|r|>2 可疑、|r|>3 认定（可自动判，
  是否剔除由「剔除」勾选框决定）。
- 相图：气相线/液相线各用一条**弧长参数化的三次 B 样条**平滑（气相线在恒沸点
  附近近乎垂直，普通 y=f(x) 样条会振荡）；恒沸点取两条曲线相差最小的位置。
- 组成不确定度：σ_x 由拟合协方差（σ_A、σ_B、σ_C）与折射率读数误差 σ_n
  经隐函数求导传播得到。
- 文献值（CRC）：恒沸点 337.95 K、乙醇摩尔分数 0.4540（质量分数 0.3128）。
  工具会把文献质量分数换算到当前口径（质量比 0.4552）再比较。

## 内置示例数据

`phase.sample_data()`（与 `data/双液系数据.json` 相同）是 2025 年秋季学期同一
实验的完整原始数据，仅用于演示与自检；界面「载入示例数据」可随时恢复。
自己的实验数据直接在表格里改即可。
