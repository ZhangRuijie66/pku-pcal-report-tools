# 电化学工具（循环伏安法解析电极极化）

从 CHI 电化学工作站导出的 `.txt` 数据出发，一键生成《循环伏安法解析电极极化》
实验报告（与课程 2026 模板同款排版的 Word 文档）。

## 实验内容（讲义 实验八）

1. N₂ 饱和硫酸中三个扫速（0.5 / 0.2 / 0.1 V·s⁻¹）的 CV 曲线 → 表1 峰电流、
   铂电极电化学活性面积（氢脱附峰电量 / 2.1×10⁻⁴ C·cm⁻²）；
2. O₂ 饱和下三种搅拌条件（快速 / 低速 / 静止）的还原支 → ORR 起始还原电位；
3. N₂ 饱和甲醇+硫酸溶液的 CV → MOR 起始氧化电位；
4. 扣空白后的 ORR（还原支）与 MOR（氧化支）→ DMFC 单池极化曲线与
   输出电压-输出功率曲线、最大输出功率。

## 用法

- 双击 `启动.vbs`（无黑框），或 `python run.py`；
- `python run.py --test` 无界面自检，报告写入 `..\实验报告输出\自检报告（电化学）\`；
- 界面左栏：数据目录（`选择文件夹…`）、封面字段、数据文件映射、处理参数；
- 右栏：KPI 卡片、图2~图10 预览、表1 与关键结果表；
- 「一键生成报告」输出到 `..\实验报告输出\<学号>-<姓名>-电化学\`（docx + figures）。

## 数据格式

CHI600B `File → Convert to Text` 导出的 txt（同目录 .csv / _red.csv 是降采样
副本，不使用）。每份文件含头部参数、峰分析表（Ep/ip/Ah）与 6 段数据；
电流为 CHI 约定（阴极为正）。报告取 Segment 5（负扫，还原支）+ Segment 6（正扫，
氧化支）。默认数据目录指向 2025 年参照数据（`物理化学实验\物理化学实验\电化学\`），
今年做完实验后在界面上改成自己的目录并「存为默认」。

## 判据与敏感参数（都在界面上可调）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 平滑窗口 | 9 点 | 展示与起始电位判据都用平滑后的曲线 |
| 起始电位阈值 | 1.0 μA | 扣空白差值沿扫描方向越过该值即判为起始；参考报告中此为「人为判定因素」 |
| ESA 积分窗口 | −0.26 ~ 0.15 V | 氢脱附峰面积（对基线） |
| 双电层基线 | 自动（0.10~0.20 V 平均） | 也可手动给定 |
| DMFC 电流网格 | 3×10⁻⁸ A 起、步长 5×10⁻⁸ A | 到两支曲线交点为止（E_cell > 0） |

用 2025 年参照数据（`chi的全部附件20251028`）验证：ESA = 1.32 mm²（参考报告 1.3）、
DMFC 交点 0.473 V（参考 0.473）、最大输出功率 3.19×10⁻⁷ W @ 0.184 V
（参考 3.25×10⁻⁷ @ 0.19，插值与读图差异内）。

## 排版口径

与燃烧热/溶解热/紫外光谱同一套规范：正文五号、标题套「标题 1/2/3」样式、
Word 原生公式；「只报数值」的句子用普通文本（变量斜体、单位正体、真上下标），
只有推导/代入计算才用公式对象。生成后必须跑
`python ..\..\课程\.dsh\skills\pku-physical-chemistry-lab-report\check_italic.py <报告.docx>`
（输出「共 0 处」才算完成）。
