- **类型**：功能
- **日期**：2026-11-19
- **说明**：新增：表面吸附可回读本工具导出的数据表（xlsx/csv），原始读数与实验条件一起恢复；桌面快捷方式支持双击生成

## 变更

- 新增：`表面吸附工具/pcal/importdata.py` —— 把「导出数据表 .xlsx / .csv」整表读回，
  恢复全部原始平行读数、实验条件（温度 / γ_w / σ）、平行次数、液柱读数方式与两臂高度总和 S
- 新增：`POST /api/import_table` 与 `GET /api/fileb64`（只读、限定浏览目录与白名单后缀）。
  回读**不落盘**，保存仍由「保存数据」负责
- 新增：界面上「回读数据表 .xlsx / .csv」按钮；数据目录里的 `.xlsx` 点一下直接整表回读，
  CSV/TXT 仍走原来的「导入类型」分列解析（两条通道语义不同，不混用）
- 修复：导出说明表补齐「吊片法温度 / σ_γ / 纯水 γ（吊片法）」三行——缺了这三行，
  数据表回读后吊片法的纯水读数与 σ 只能沿用界面旧值
- 新增：根目录 `创建桌面快捷方式.vbs` —— 双击即重建桌面快捷方式，无命令行窗口，
  建完弹原生消息框告知成功或失败（`_tools/创建快捷方式.py --interactive`）
- 修复：`生成vbs.py` 里 `FindPython` 改为单一来源 `PY_FINDER` 供各模板共用，
  避免复制粘贴把三引号写成四引号（VBScript 报「缺少 ')'」，报错行看着却完全正常）

## 验收

- 往返一致性：示例数据导出 → 回读 → 重新分析，Γ∞ / q / σ / 各点 γ 逐位相同
- 数量鲁棒性：平行 1 / 2 / 5 / 6 次、浓度点 2 / 8 个、只有一种方法、两法次数不同（5/2）
- 口径保真：只读一侧（`height_mode=left`）回读后 σ(Δh) 仍是「S − 2h」的两倍灵敏度口径（0.0632），
  未退化成两侧实测算的 0.0400
- 双击入口：`wscript 创建桌面快捷方式.vbs` 返回 0，运行期间新增可见控制台窗口 0 个
- 全量回归：548 项全部通过
