# v1.1.0

- **类型**：功能
- **日期**：2026-11-09
- **说明**：启动反馈、可移植性、文件选择与搜索三项改造：启动画面 + 入口页骨架屏 + 模块启动过渡页（不再白屏等待）、依赖探测缓存把启动从约 3 秒降到约 1 秒、11 个模块统一可移植数据目录与可搜索文件选择器、文件名模糊匹配下沉为共享层

## 变更

### 一、启动反馈：不再「点了没反应」

以前双击快捷方式到浏览器出现页面之间有约 2~3 秒**完全没有任何窗口**，用户
容易以为没点上而反复双击；点「启动这个模块」后模块要 1.2~4.7 秒才起来，
这段时间浏览器里是一个**纯白标签页**。

- 新增 `_tools/splash.py` 启动画面：无边框小卡片 + 流动进度条，实测
  **0.28 秒**可见；它自己轮询入口端口区间（8700–8729），端口一通立刻关闭，
  慢机器多显示一会儿、快机器一闪而过，**不占主启动链路时间**。
- 入口页加**骨架屏**：首屏在 `/api/modules` 回来之前先摆 6 张带微光动画的
  占位卡片，不再是白屏；`prefers-reduced-motion` 下动画自动关闭。
- 入口页卡片加**启动中状态**：按钮变「正在启动…」并**实时走秒数**，模块转圈
  提示，避免重复点击。
- 新增模块启动过渡页 `物化实验报告工具/web/boot.html`：点「启动这个模块」
  时打开的是它（不是 `window.open('')` 的空窗口）——转圈、三步进度、
  已等待秒数，超过 15 秒自动给出排查指引（回入口页看状态 / 查启动日志）。
- 入口服务新增 `/static/` 路由（白名单 + `normpath` 越界检查，
  `/static/../profile.json` 这类请求返回 404）。

### 二、启动提速

- **依赖探测缓存**：每次启动都开 4~5 个子进程逐个 `import numpy/scipy/
  matplotlib/docx` 检查依赖，实测 **1.26 秒**，占启动链路四成。现在缓存到
  `_tools/deps_cache.json`（按 Python 路径 + 依赖清单指纹，7 天过期；
  缓存说缺的项仍会真探一次，避免刚装好还弹安装窗口），命中只要
  **0.008 秒**。
- 去掉 `launcher.start()` 里写死的 `time.sleep(1.5)`，改成 0.1 秒间隔轮询：
  进程秒退能立刻报错，正常启动也不用白等。
- 综合效果：双击到浏览器可用从约 **2.9 秒**降到约 **1.1 秒**，且这 1 秒里
  屏幕上已经有启动画面。

### 三、可移植性

- 新增共享层 `_core/dataloc.py`：统一的 `find_data_dir()` 按
  「记住的目录 → 套件根/数据 → 该实验候选 → 工具子目录 → 工具目录本身」
  依次探测，**最后一档保证返回一个存在的目录**，换机器不会
  `FileNotFoundError`，也不写死任何盘符。
- 11 个模块的默认数据目录全部改走它：以前多数模块默认 `None`/空
  （打开后一片空白，必须自己点「选择文件夹」），现在换台电脑打开就是可用的。
- `_core/profile.py` 新增 `personal()`：`run.py --test` 里硬编码的
  姓名/学号（原来有「张瑞杰/2400011877」「李晨曦/2300012602」两套）改为读
  `profile.json` 个人档案，**读不到就留空并提示**——可移植包被别人的电脑
  解压后，自检报告不会印出作者的名字。
- 11 个 `run.py` 加 **GBK 控制台兜底**：自检打印的 `⚠`/`·`/`Δ`/`α` 在
  cp936 控制台会抛 `UnicodeEncodeError` 把整个 `--test` 打断（只影响打印，
  不该中止计算），现在 `sys.stdout.reconfigure(errors='replace')` 兜住；
  11 个模块在 `PYTHONIOENCODING=cp936` 下实测全部退出码 0。

### 四、文件选择与搜索

- 新增 `_core/filepick.py`：系统「选择文件夹 / 选择文件」窗口统一走
  tkinter 子进程（不阻塞 HTTP 服务），自动化测试用
  `PCAL_PICK_AUTO` / `PCAL_PICK_FILE_AUTO` 接管。
- 新增前端组件 `_core/web_files.js`（同步为各模块 `web/files.js`）：
  `PcalFiles.mount()` 提供**可搜索的文件选择器**——搜索框、文件列表
  （名字 + 所在子目录）、匹配计数、空状态指引、`refresh()`。
  搜索顺序与后端同口径：子串 > 子序列 > 模糊相似度。
- 11 个模块全部接上：`GET /api/files`（目录清单）、`GET /api/pickfile`
  （选单个文件）、`GET /api/pickdir`（选文件夹）。只读端点一律挂 `do_GET`，
  取文件端点只允许浏览目录内部（`resolve_rel` 拒穿越）+ 后缀白名单 +
  体积上限，不提供按绝对路径读任意本地文件的能力。
- **电化学模块**的「数据文件映射」升级为自动匹配：7 个槽位按相似度打分，
  ≥0.80 自动采用、≥0.45 进候选，界面标出「自动 NN%」并可一键全部匹配 /
  恢复默认；匹配结果沿用原有 `file_*` 配置持久化。

### 五、文件名模糊匹配（下沉为共享层）

- `_core/dataloc.py` 提供 `match_score / rank_candidates / auto_match`：
  `0.74·语义后缀 + 0.20·整名 + 0.04·同目录 + 0.02·同时间戳`，
  权重之和正好 1.0 且**不提前饱和**。
- 剥掉时间戳前缀（`2026-10-21 & 12-56-02-`）与无歧义复制后缀
  （`- 副本`、`(2)`、`_copy`）后再比对语义后缀，所以换一天重测、
  别人改过文件名都还能匹配上。

## 修复

- **尾号 `_数字` 不再被当成复制后缀剥掉**（`split_stamp` 改为默认保留，
  需要剥时传 `strip_tail_number=True`）。电化学的 `N2_1 / N2_2 / N2_5`
  是三个**不同扫速**（0.1/0.2/0.5 V·s⁻¹），剥成 `N2` 后三个槽位同分并列、
  会互抢同一份文件，峰电流与电化学活性面积全错而界面看不出区别。
  这类「静默选错数据文件」是本项目最难发现的错误类别。
- 空数据目录的提示改成可操作：「这个文件夹里没有找到数据文件（<路径>）。
  把课程软件导出的数据文件放进这个文件夹，再点『刷新』。」
