# v1.3.0

- **类型**：修复
- **日期**：2026-11-09
- **说明**：可移植性审计第二批——**数量变化**鲁棒性：修正电导率两点拟合丢失点估计的缺陷，并为 11 个模块补齐「测量次数 / 数据点数 / 样品个数变化」的行为契约与回归测试

## 背景

上一轮处理的是「路径与文件名写死」。这一轮查的是另一类不可移植：
**换个人做实验、测的浓度档次不同、平行读数次数不同**时会不会坏。

判断标准是三条，缺一不可：
1. 数量变了照常算对；
2. 算不了时**明确说清为什么**（警告/报错），不能静默给 `nan`／空表；
3. **点估计与不确定度分开**——数量不够算不出 σ，不代表连值都给不出。

## 修复

### 电导率：两点数据丢失点估计（真 bug）

`line_fit()` 原来写死 `if n < 3: 全部返回 NaN`，于是**只有 2 个浓度点时，
斜率 k 与截距 b 也被一起丢掉**，`Λm∞` 变成 `nan`，报告里一片「—」。

两点其实**唯一确定一条直线**，斜率与截距是精确解；只有残差自由度
`n−2 = 0` 才导致不确定度无定义。现在：

| 点数 | k、b（点估计） | σk、σb、r |
| --- | --- | --- |
| 0 | NaN（没有数据） | NaN |
| 1 | NaN（过一点有无数条直线） | NaN |
| **2** | **照常给出**（差分精确求解） | NaN（自由度 0，无定义） |
| ≥3 | 给出 | 给出 |

配套在 `analysis.py` 加警告：「×× 只有 2 个浓度点：Λm∞ 与 B 按两点连线给出
（点估计精确），但无法估计不确定度，报告里对应位置显示「—」。」
这样用户能分清「工具不支持」与「数据有问题」。

**回归**：默认 5 点数据的 Λm∞ 与 σ 与改动前逐位一致
（NaNO₃ 0.01214±0.00020、NaAc 0.00912±0.00010、HNO₃ 0.04286±0.00072），
警告数为 0。

## 审计结论（逐模块实测，无代码改动项）

这一轮把 11 个模块逐一用「不同数量」的数据跑了一遍，以下**均已正确**，
并写进 `tests/test_quantity_robustness.py` 钉住：

| 模块 | 变化量 | 实测结果 |
| --- | --- | --- |
| 表面吸附 | 平行读数 1/2/3/5/6 次 | 次数被正确采用；纯水 γ 稳定在 71.19 |
| 表面吸附 | 两法次数不同（5/2） | 各取各的，不串 |
| 表面吸附 | 某法数据全空 | 另一法照常，给出「线性区选点少于 2 个」警告 |
| 蒸气压 | 拟合点 2/3/4/6/10 | 任意点数 A、B 与手算最小二乘一致 |
| 蒸气压 | 点数不足 3（含大气压沸点） | 不给 fit + 明确警告，不静默出数 |
| 蒸气压 | 空系列 | 不崩、不给 fit |
| 偶极矩 | 溶液点 3/4/5 | μ 有限且量级正确（1.57/1.61/1.66 D） |
| 偶极矩 | 溶液点 2 | μ=NaN **但明说「不足 3 组」**（外推本就需 ≥3 组，属预期） |
| 偶极矩 | 比重瓶读数 1/2/3/4 次 | 都能给出密度 |
| 磁化率 | 样品 0/1/2/3 个 | 输出行数与输入一致；0 个不崩 |
| 磁化率 | 反磁性样品 | μ 为 `None`（无永久磁矩），不是 `nan` |
| 双液系 | 工作曲线 3~7 点、沸点 5~16 条 | 输出点数与输入一致；R²/恒沸组成合理 |
| 化学动力学 | 组数 2~5、每组点数 30%~100% | 各组 k 均为正有限数 |
| 紫外光谱 | 浓度档次/重复测量次数 | `pick_choices` 覆盖全部；任意选择都落到合法样品 key |
| 紫外光谱 | Beer 拟合点数 1/2/3/4/6 | 1 点自动停用；高浓度点混入时 R² 下降（物理预期） |
| 燃烧热 | 轮次 < 2 | 明确抛「至少需要两轮数据」（标准物质 + 待测） |

其中几处**本来就是对的、值得保留的设计**，审计时特别确认过：
- 蒸气压、偶极矩在点数不足时给的是**明确警告**而不是静默 `nan`；
- 燃烧热的「至少两轮」是硬性前置条件，报错信息可读；
- 磁化率 0 个样品也能正常返回空表，而不是抛异常。

## 验证

- `python tests/run_tests.py`：**346 项全过**（新增
  `tests/test_quantity_robustness.py` 25 项 + 上轮 UI 修复带入的用例）。
- 手算核对：蒸气压任意点数的 A/B 与 `numpy.polyfit` 逐位一致
  （注意模块用 `ln(p/100 kPa)`，`R_GAS = 8.314`）。
- 电导率默认数据回归：Λm∞/σ 与既有基准逐位一致。

## 已知且**不打算改**的行为

- 偶极矩 < 3 组溶液点时 μ 为 NaN：Hedestrand 外推需要至少 3 个浓度点才能做
  外推，2 组时给数反而是错的。已有明确警告。
- 电导率 2 点时 σ 为空：自由度确实为 0，编一个数会误导。
