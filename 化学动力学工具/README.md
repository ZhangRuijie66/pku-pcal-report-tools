# 化学反应动力学探究 · 报告生成器

数智旋光仪监测蔗糖在盐酸催化下的水解：旋光度–浓度标定、各级反应尝试、
`k₁` / `t₁/₂`、`k₁–c(H⁺)` 非线性拟合与 lg–lg 验证，一键生成课程 2026 模板的 Word 报告。

## 启动

```bat
双击 启动.vbs
:: 或
python run.py
python run.py --port 8812 --no-browser
python run.py --test
```

默认端口 **8811**，也可以从统一入口进入。依赖 `openpyxl`（读 Polariputer 的 xlsx）。

## 数据录入

- **动力学分组**：每组一个卡片，填编号（如 `4M`）、标称酸浓度、真实 `c(H⁺)`、
  α∞ 覆盖值（可空）、剔除点序号，以及 `t α` 两列数据。
- **导入 Polariputer xlsx**：点分组卡片里的「导入 xlsx/CSV」，选择动态测量保存的
  `.xlsx`（自动读 `time` / `angle` 列与实验温度）；也支持两列 CSV/TXT。
- **标定表**：可直接填 `c, α`，或点「导入标定表」读 CSV/TXT/xlsx。
- **载入示例数据**：2025 年同课程报告的数据（5 个盐酸浓度），用于预览流程。
- **保存数据**：写入 `data/化学动力学数据.json`。

## 计算

```
标定：α = k·c + b（可剔离群点，画 95% 置信带）
α₀ = k·c₀ + b,  c₀ = 蔗糖母液浓度 / 2
α∞：实验值或 α₀·(M_glu/M_suc)·([α]_glu+[α]_fru)/[α]_suc
零级：α–t；一级：ln(α−α∞)–t；二级：1/(α−α∞)–t
k₁ = −slope,  t₁/₂ = ln2/k₁
k₁ = k₀ + k_H c(H⁺)^n     （非线性最小二乘）
lg(k₁−k₀) = lg k_H + n lg c(H⁺)   （线性验证）
```

- 级数判定默认用 `order_group` 指定的组（默认 `4M`）；界面可切换。
- 每组可单独剔除异常点（序号从 1 开始）；所有组默认使用同一个 α∞，也可在组内覆盖。
- 结果表给出各组 `k₁`、`t₁/₂`、`R²`、有效点数；下方给出级数判定、`n` 与 α∞ 对比。
