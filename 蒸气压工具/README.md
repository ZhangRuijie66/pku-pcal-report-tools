# 液体饱和蒸气压 · 实验报告生成器

北京大学物理化学实验「液体饱和蒸气压的测定」的报告生成工具，
与燃烧热 / 溶解热 / 紫外光谱 / 表面吸附 / 化学动力学工具同一套架构
（原始数据 → 计算内核 → 本地网页 → Word 报告）。

## 实验

- **动态法测水**：改变外压（约 50 kPa → 大气压），记录沸腾温度；
- **静态法测环己烷**：平衡管等压计，从大气压逐次降压约 5 kPa 至 50 kPa，
  在 b、c 两管液面相平时记录温度与压力。

处理口径与课程数据处理表（`蒸发热数据处理.xlsx`）及 2025 年参考报告一致：

```
T/K = t/℃ + 273.15
y = ln(p/p⊖)（p⊖ = 100 kPa，只为消除量纲）
y = −A/T + B      ← 最小二乘拟合（参数不确定度用 OLS 标准误）
T_b = A/(B − ln(p₁/p⊖))，p₁ = 101.3 kPa
Δ_vap H_m = A·R
Δ_vap S_m = Δ_vap H_m / T_b（与楚顿规则 88 J·mol⁻¹·K⁻¹ 比较）
```

## 启动

- 双击 `启动.vbs`（无黑框后台启动，自动打开浏览器）；或
- `物化实验报告工具\启动入口.vbs` 统一入口里点「液体饱和蒸气压的测定」卡片；或
- `python run.py`（调试用；`--port N`、`--no-browser`）。

默认端口 8761，被占用时自动 +1 往后找。

## 用法

1. **导入数据**：点「选择文件」直接选课程数据处理用的 `xlsx`
   （如 `物理化学实验\物理化学实验\蒸气压\蒸发热数据处理.xlsx` 的 5 列格式，
   自动取前两列 p、t），或 csv/txt、或把 (p, t) 两列粘进文本框。
   工具按「温度骤降 > 10 ℃」自动把 22 行数据切成水 / 环己烷两支，
   每支里与最高压强相差 ≤1.5 kPa 的行识别为「大气压沸点」；
   也可以在左侧表格里手工输入/微调。
2. **核对结果**：右侧预览 4 张图（p–T 光滑曲线、ln(p/p⊖)–1/T 拟合线 ×2），
   结果表给出 A、B、R²、T_b、Δ_vap H_m、Δ_vap S_m 及与文献值的相对偏差。
3. **填封面**：姓名 / 学号 / 组别 / 实验日期 / 室温 / 大气压强
   （数据文件里没有室温大气压，要自己填）。「存为默认」写进 `settings.json`。
4. **一键生成报告 (.docx)**：输出到
   `..\实验报告输出\<学号>-<姓名>-蒸气压\<学号>-<姓名>-蒸气压.docx`，
   图在同名 `figures\` 子目录里，整个文件夹可直接拷走上交。

## 报告内容（完整版，照 2025 年参考报告的结构）

摘要/关键词 → 1 引言（预留预习图片位置，把扫描件拖进 `assets\引言图.jpg` 即可自动插入）
→ 2 实验部分 → 3 数据与结果（每支液体：原始数据表 ×2、最终数据表、
光滑曲线图、拟合直线图、T_b / Δ_vap H_m / Δ_vap S_m 及其不确定度的完整推导；
水另有一节「整体温度偏高 1.0 ℃ 的复算」）
→ 4 讨论与结论（4.1 水的误差分析、4.2 环己烷的误差分析、
4.3 与楚顿规则的比较、4.4 小结汇总表）→ 参考文献。

默认文献值（可在界面改）：水 T_b 373.15 K、Δ_vap H_m 41.07 kJ·mol⁻¹
（CRC，82~100 ℃ 平均）；环己烷 T_b 353.9 K、Δ_vap H_m 31.45 kJ·mol⁻¹
（Jochems 1982）。

## 自检

```
python run.py --test
```

用内置示例数据（即 `蒸发热数据处理.xlsx` 那一批）走完整计算 + 出报告流程，
输出到 `..\实验报告输出\自检报告（蒸气压）\`。示例数据下的期望值：

| 量 | 水 | 环己烷 |
| --- | --- | --- |
| A | (4.970 ± 0.030)×10³ K | (3.824 ± 0.012)×10³ K |
| B | 13.294 ± 0.082 | 10.840 ± 0.036 |
| T_b | (374.2 ± 3.2) K | (353.2 ± 1.6) K |
| Δ_vap H_m | (41.32 ± 0.25) kJ·mol⁻¹ | (31.79 ± 0.10) kJ·mol⁻¹ |
| Δ_vap S_m | (110.4 ± 1.2) J·mol⁻¹·K⁻¹ | (90.0 ± 0.5) J·mol⁻¹·K⁻¹ |
