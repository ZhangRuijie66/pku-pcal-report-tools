# 液体饱和蒸气压 · 实验报告生成器

北京大学物理化学实验「液体饱和蒸气压的测定」的报告生成工具，
与燃烧热 / 溶解热 / 紫外光谱 / 表面吸附 / 化学动力学工具同一套架构
（原始数据 → 计算内核 → 本地网页 → Word 报告）。

## 实验

- **动态法测水**：改变外压（约 50 kPa → 大气压），记录沸腾温度；
- **静态法测环己烷**：平衡管等压计，从大气压逐次降压约 5 kPa 至 50 kPa，
  在 b、c 两管液面相平时记录温度与压力。

处理口径与课程数据处理表（`蒸发热数据处理.xlsx`）及 2025 年参考报告一致：

```
T/K = t/℃ + 273.15
y = ln(p/p⊖)（p⊖ = 100 kPa，只为消除量纲）
y = −A/T + B      ← 最小二乘拟合（参数不确定度用 OLS 标准误）
T_b = A/(B − ln(p₁/p⊖))，p₁ = 101.3 kPa
Δ_vap H_m = A·R
Δ_vap S_m = Δ_vap H_m / T_b（与楚顿规则 88 J·mol⁻¹·K⁻¹ 比较）
```

## 用法

1. **导入数据**：点「选择文件」直接选采集软件导出的 `csv` / `xlsx`，
   或把 (p, t) 两列粘进文本框。
   **水和环己烷通常来自两个文件**（`水.csv`、`环己烷.csv`）：先导一个，
   再导另一个，两次会按液体**合并**，后一次不会把前一支抹掉。

   读文件的判据（2026-11-25 重写，旧版对真实日志读出 **0 行**）：

   | 情况 | 处理 |
   | --- | --- |
   | 第一列是采集时间（`13:27:11.033`、`53:03.0`） | 识别为时间，**不当数值**；只靠表头 `pressure` / `temperature` 认列 |
   | 带表头 `time, pressure(KPa), temperature(°C)` | 按表头认列，表头行不当数据 |
   | 无表头（2025 那批 5 列处理表） | 跳过时间列，取前两个数 |
   | GBK 编码（`°C` 在 cp936 是单字节） | 先试 `utf-8-sig`，失败退回 `gbk` |

   读数自动分到水 / 环己烷两支，判据**不是**「温度骤降」（水的第一段是
   20 ℃ 左右未沸腾的检漏读数、温度是上升的；环己烷末尾通大气那一行温度
   骤降 22 ℃ 会被误判成换液体），而是：

   1. 气液平衡点必然落在**同一条 ln(p/p⊖)–1/T 直线**上 → 两点枚举找内点最多的那条；
   2. 物理校验：A = −斜率 > 0、温度跨度 ≥ 10 K、外推常压沸点接近水 373 K 或环己烷 354 K；
   3. 剩下的读数里再找第二条曲线（另一支液体）；
   4. 常压沸点相差 < 12 K 视为同一种液体测了两遍，合并。

   没有进任何一支的读数会**逐行列在「被排除的读数」卡片里**（偏离平衡线多少、
   判归哪一支），报告 3.x.1 也会多一张表交代。与最高压强相差 ≤1.5 kPa
   （且 ≥95 kPa）的点识别为「大气压沸点」，取平均后参与拟合，
   **平行几次就有几行**，不再限定 3 行。
2. **核对结果**：右侧预览 4 张图（p–T 光滑曲线、ln(p/p⊖)–1/T 拟合线 ×2），
   结果表给出 A、B、R²、T_b、Δ_vap H_m、Δ_vap S_m 及与文献值的相对偏差。
3. **填封面**：姓名 / 学号 / 组别 / 实验日期 / 室温 / 大气压强
   （数据文件里没有室温大气压，要自己填）。「存为默认」写进 `settings.json`。
4. **一键生成报告 (.docx)**：输出到
   `..\实验报告输出\<学号>-<姓名>-蒸气压\<学号>-<姓名>-蒸气压.docx`，
   图在同名 `figures\` 子目录里，整个文件夹可直接拷走上交。

## 报告内容（完整版，照 2025 年参考报告的结构）

摘要/关键词 → 1 引言（预留预习图片位置，把扫描件拖进 `assets\引言图.jpg` 即可自动插入）
→ 2 实验部分 → 3 数据与结果（每支液体：原始数据表 ×2、最终数据表、
光滑曲线图、拟合直线图、T_b / Δ_vap H_m / Δ_vap S_m 及其不确定度的完整推导；
**有读数被排除时多一张「未参与拟合的读数」表**，表号按出现顺序连续；
水另有一节「整体温度偏高 1.0 ℃ 的复算」）
→ 4 讨论与结论（4.1 水的误差分析、4.2 环己烷的误差分析、
4.3 与楚顿规则的比较、4.4 小结汇总表）→ 参考文献。

默认文献值（可在界面改）：水 T_b 373.15 K、Δ_vap H_m 41.07 kJ·mol⁻¹
（CRC，82~100 ℃ 平均）；环己烷 T_b 353.9 K、Δ_vap H_m 31.45 kJ·mol⁻¹
（Jochems 1982）。

## 自检

```
python run.py --test
```

用内置示例数据（即 `蒸发热数据处理.xlsx` 那一批）走完整计算 + 出报告流程，
输出到 `..\实验报告输出\自检报告（蒸气压）\`。示例数据下的期望值：

| 量 | 水 | 环己烷 |
| --- | --- | --- |
| A | (4.970 ± 0.030)×10³ K | (3.824 ± 0.012)×10³ K |
| B | 13.294 ± 0.082 | 10.840 ± 0.036 |
| T_b | (374.179 ± 0.066) K | (353.166 ± 0.040) K |
| Δ_vap H_m | (41.32 ± 0.25) kJ·mol⁻¹ | (31.79 ± 0.10) kJ·mol⁻¹ |
| Δ_vap S_m | (110.42 ± 0.68) J·mol⁻¹·K⁻¹ | (90.01 ± 0.30) J·mol⁻¹·K⁻¹ |

⚠️ T_b 的不确定度只有 ±0.07 K：**必须保留 A、B 的协方差项**。若当作独立量
做平方和，会得到 ±3.2 K（高估约 49 倍），而 A、B 出自同一次最小二乘、
相关系数 0.99987，那个数是错的。同理 Δ_vap S_m = R·(B − ln(p₁/p⊖))
与 A 严格无关，σ 只由 σ_B 传播（按 σ_ΔH、σ_Tb 合成会高估约 70%）。

## 2025 示例数据之外的实测（2026-11-25）

用用户 2026-11-25 采集的两份真实日志（`tests/fixtures/蒸气压/`）核对：

| | 原始行数 | 进拟合 | 排除 | Δ_vap H_m |
| --- | --- | --- | --- | --- |
| 水.csv | 15 | 11（10 个变压点 + 1 个大气压沸点） | 4（检漏时 28~29 ℃） | 41.34 kJ·mol⁻¹ |
| 环己烷.csv | 26 | 11（10 个降压点 + 12 个大气压读数取平均） | 4（3 个检漏 + 1 个通大气后 59.6 ℃） | 32.29 kJ·mol⁻¹ |

水的 A = 4972.9891 K、σ_A = 13.9230 K 与**用户自己 Origin 工程
（`20261125.opju`）里的拟合结果逐位相同**，可作外部基准。

## 文件结构

```
蒸气压工具/
├─ 启动.vbs / 启动.cmd        无黑框启动器（见 _tools\生成vbs.py）
├─ run.py                     python run.py；--test 无界面自检

├─ data/蒸气压数据.json       界面里保存的数据（不进 git）
└─ pcal/
    ├─ vapor.py               数据解析（xlsx/csv/文本）+ 克氏拟合 + 不确定度
    ├─ analysis.py            参数模型
    ├─ plotting.py            p–T 光滑曲线 + 拟合直线（600 dpi）
    ├─ report.py              报告正文

```
