# 溶解热实验报告一键生成

北京大学物理化学实验（2026 秋）—— **溶解热的测定** 模块。
从课程软件导出的原始数据出发，在本地网页界面里交互式处理（等面积雷诺校正取点、
积分溶解热拟合核对），一键导出与课程 2026 模板同款的 Word 实验报告。

## 启动

- 双击 `启动.cmd`（只需第一次联网装依赖）
- 或 `python run.py`；界面在 `http://127.0.0.1:8741`（端口被占会自动往后找）
- 无界面自检：`python run.py --test` → 生成 `输出\自检报告.docx`

> 也可以从上级目录的 **`物化实验报告工具`** 统一入口一次启动全部实验模块，
> 在入口页选项目。两个工具互不依赖，单独双击本目录的 `启动.cmd` 一样能用。

## 这个实验在做什么

保温瓶式简易量热计 + **电热补偿法**。先记录硝酸钾溶解过程（吸热、温度下降）的
温差-时间曲线，再通电加热使体系沿原途径回到原温度，得到加热过程（温度回升）的曲线。
两条曲线各做一次**等面积雷诺校正**扣除体系与环境的热交换，代入

```
Q = Q' · (T₂ − T₁) / (T₂' − T₁')        Q' = I²Rt
```

即得每次加入溶质所吸收的热量。实验用**累加法**加入 6 份 KNO₃，得到 6 个浓度下的
积分溶解热，并用经验方程 `Qs = Qs0·a·n0/(1+a·n0)` 拟合，再由解析导数给出
微分溶解热、微分冲淡热与积分冲淡热。

## 算法出处与核对

计算内核 `pcal/dissolution.py` 复刻课程软件源码 `maths.py`
（作者赵泽华，GPL-3.0，<https://github.com/Zhao-Zehua/Dissolution-Combustion>）：

| 步骤 | 复刻的函数 |
| --- | --- |
| 最小二乘直线拟合 | `linear_regression` |
| 等面积雷诺校正（B 样条 + 等面积求根） | `Reynolds` |
| 溶解热 Q = Q'·ΔT_d/ΔT_h | `calculate_dissolution` |
| 积分溶解热与经验方程非线性拟合 | `dissolution_heat_regression` |
| 微分溶解热 / 微分冲淡热 / 积分冲淡热 | `dissolution_heat_test` |

用本套数据核对（`dissolution.csv` 里软件自己记录的取点）：

| 轮次 | 软件 Q / kJ | 本程序 Q / kJ |
| --- | --- | --- |
| 1 | 4.3900 | 4.3900 |
| 2 | 4.3703 | 4.3703 |
| 3 | 4.1471 | 4.1471 |
| 4 | 1.7007 | 1.7007 |
| 5 | 2.0298 | 2.0298 |
| 6 | 2.6237 | 2.6237 |

拟合：`Qs0 = 37.6486 kJ/mol`、`a = 0.323594`、`R² = 0.953805`
（软件：`37.6481`、`0.323694`，差异只来自 csv 里只有 6 位有效数字）。

## 误差分析的口径（4.3.1 / 4.4）

按本课程报告一贯的做法，**直接给各量的标准差**（不是仪器允差除以 √3）：

| 量 | 取值 | 依据 |
| --- | --- | --- |
| 电流 σ_I | 0.01 A | 电流很稳定，保守估计 |
| 电阻 σ_R | 0.2 Ω | 实验前后相差约 0.15 Ω，接触电阻使读数偏大 |
| 通电时间 σ_t | 0.7 s | 单次计时 0.5 s，两次之差按 √2 合成 |
| 校正温差 σ_ΔT | 0.01 K | 单次测温 0.005 K，一个温差是两点相减 |

σ_ΔQ 由式(12)按绝对形式传播，等价于相对形式
`σ_Q/Q = √[(2σ_I/I)² + (σ_R/R)² + (σ_t/Δt)² + (σ_ΔT/ΔΔT)² + (σ_ΔT/ΔΔT')²]`。
以第 3 组为例：电流项 82.1 J、电阻项 77.0 J、加热温差 26.3 J、溶解温差 24.0 J、
时间 8.4 J，合成 **σ_ΔQ = 118 J ≈ 0.12 kJ**（电流与电阻各占约 4 成方差）；
累加三组得 σ_Q = 0.21 kJ，σ_Qs = 0.59 kJ·mol⁻¹。这些数都可以在界面上改。

4.4 节把拟合出的 Qs⁰ 与手册值比较：**25 ℃ 下 KNO₃ 的无限稀释积分溶解热
34.89 kJ·mol⁻¹**（本课程此前报告用的值，CRC Handbook）。本次 37.65 kJ·mol⁻¹，
相对误差 **7.9%**，偏大——原因同样沿用此前报告的分析：加热时间（约 344 s）
远长于溶解时间（约 139 s），两段热交换补偿不对称。

## 需要留意的地方

- **取点直接决定结果**：一次实验要做两次雷诺校正（溶解段、加热段），
  溶解热正比于 ΔΔT/ΔΔT'。界面默认用 `dissolution.csv` 里你当时在软件里选的取点。
- **中间平台（B）的线性最差**：本套数据里平台 B 夹在溶解降温与通电升温之间，
  窗口最短，而且溶解的余热弛豫与通电升温在时间上**部分重叠**，
  所以它的 R² 只有 0.4~0.9（两端平台都在 0.9 以上）。我把 End2 往左挪试过，
  R² 反而更差（0.2 上下）——说明这不是取点不当，而是数据本身如此。
  3.2.2 节已如实说明，并指出两次校正共用同一条 B 直线、其偏差在很大程度上相互抵消。
