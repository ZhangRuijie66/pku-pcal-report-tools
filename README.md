# 物理化学实验报告工具集

北大物理化学实验的五套报告工具 + 一个统一入口，全部在**本机**运行，
不联网、不上传数据，一键导出与课程模板同款的 Word 报告（含 Word 原生公式）。

| 模块 | 目录 | 做什么 |
| --- | --- | --- |
| 🧪 燃烧热的测定 | `燃烧热工具/` | 氧弹量热计；苯甲酸标定量热计常数 W，雷诺校正求恒容/恒压燃烧热 |
| 💧 溶解热的测定 | `溶解热工具/` | 电热补偿法测 KNO₃ 积分溶解热，拟合 Q–n₀ 求微分溶解热/微分冲淡热 |
| 🌈 紫外可见吸收光谱 | `紫外光谱工具/` | 光谱仪标定、6 种共轭分子的 λmax/ε、一维势箱验证、Voigt 分峰、TD-DFT 对照 |
| 🧴 溶液表面吸附 | `表面吸附工具/` | 最大气泡压力法 + 吊片法测表面张力，Gibbs 吸附求 Γ∞、q、q_c |
| ⏱️ 化学动力学 | `化学动力学工具/` | 数智旋光仪测蔗糖水解，积分法判级数、求 k₁ 与氢离子级数 |
| 🚪 统一入口 | `物化实验报告工具/` | 一个卡片页，一次拉起全部已安装模块 |

## 快速开始

### 一键入口（推荐）

双击 **`启动入口.cmd`**（或 `python 物化实验报告工具\run.py`），浏览器会打开
`http://127.0.0.1:8700` 的卡片页，点哪张卡片就进哪个实验的界面。

> 关闭那个黑色命令行窗口 = 停止入口和它拉起的全部模块。

### 单独启动某个模块

```bat
python 燃烧热工具\run.py
python 溶解热工具\run.py
python 紫外光谱工具\run.py     :: 默认 http://127.0.0.1:8791
```

每个模块也可以直接双击它自己的 `启动.cmd`。

## 安装依赖

```bash
python -m pip install -r requirements.txt
```

需要 Python 3.10+（推荐 3.11）。依赖只有 `python-docx`、`numpy`、`scipy`、`matplotlib`、`openpyxl`。
Windows 上首次运行 `启动.cmd` 也会自动装。

## 各模块做什么

### 燃烧热工具

读课程软件导出的温度–时间数据，雷诺校正取 ΔT，苯甲酸标定 W，计算样品燃烧热
（含点火丝、棉线修正），报告里给表格与燃烧焓对照。支持软件取点 / 手选取点。

### 溶解热工具

累加法测不同 n₀ 下的积分溶解热，拟合经验方程并求微分溶解热、微分冲淡热；
报告含 Q–n₀ 曲线、拟合参数表与讨论。

### 紫外光谱工具

- 用氘灯特征谱线标定 pixel→波长（线性拟合 R² 显示在界面）；
- 6 种共轭分子（A1~A4、B1、B2）的吸收光谱，自动寻峰得 λmax，Beer–Lambert 拟
  合求 ε；
- 一维势箱模型验证、Voigt 分峰（A3）、光源/杂散光校正；
- **高斯计算（TD-DFT）**：可以从同级的 `高斯计算工具` 读取 TD-DFT 结果，
  界面显示「计算 λmax / f」，并把计算–实验对照表自动写进报告 3.5 节。

> TD-DFT 对照需要另一个仓库的 [高斯计算工具](https://github.com/ZhangRuijie66/Chemdraw-To-Gaussian)
> 与本目录同级（`…/物理化学实验/高斯计算工具/`）；没有它时其他功能不受影响。

### 表面吸附工具

两种方法并列：最大气泡压力法（录入左右液柱高度，自动算 Δh、扣除零点）和吊片法
（录入三次表面张力读数）。作 γ–lg c（讲义口径）或 γ–ln c（旧报告口径）图，
选高浓度线性区拟合得 Γ∞、q，并计算浓度修正后的 q_c 与相对偏差。
数据可手工录入，也可从 CSV/TXT 导入；示例数据来自同课程 2025 年报告，仅作演示。

### 化学动力学工具

直接导入 Polariputer 动态测量保存的 xlsx（列 `time` / `angle`），也可以粘贴两列
`t α`。先作旋光度–浓度标定（可剔离群点、画 95% 置信带），再对每组作零级/一级/二级
线性化判定蔗糖级数，给出 k₁、t₁/₂，最后由 k₁–c(H⁺) 非线性拟合与 lg–lg 线性拟合
确定氢离子反应级数。示例数据同样来自 2025 年报告。

## 报告输出

点「一键生成报告 (.docx)」，输出到 `…/物理化学实验/实验报告输出/<学号-姓名-实验>/`，
报告和插图在一个文件夹里，直接打包上传即可。报告使用课程模板（封面、中文排版、
Word 原生公式 OMML、五号字、图表题注）。

## 说明

- `settings.json`（个人姓名/学号/数据目录等）**没有**提交到仓库，首次运行会自动生成，
  点界面右上角「存为默认」即可保存；
- 原始数据目录（`1 燃烧热/`、`2 溶解热/`、`3 紫外光谱搭建/`）与导出报告也不在仓库里；
  表面吸附/化学动力学两个模块的原始数据存在各自的 `data/*.json`，同样不提交；
- 每个模块都是独立进程、独立 `pcal` 包，入口只负责挑端口、拉起子进程、做健康检查、
  退出时收摊。
