# 物理化学实验报告工具集

北大物理化学实验的八套报告工具 + 一个统一入口，全部在**本机**运行，
不联网、不上传数据，一键导出与课程模板同款的 Word 报告（含 Word 原生公式）。

| 模块 | 目录 | 做什么 |
| --- | --- | --- |
| 🧪 燃烧热的测定 | `燃烧热工具/` | 氧弹量热计；苯甲酸标定量热计常数 W，雷诺校正求恒容/恒压燃烧热 |
| 💧 溶解热的测定 | `溶解热工具/` | 电热补偿法测 KNO₃ 积分溶解热，拟合 Q–n₀ 求微分溶解热/微分冲淡热 |
| 🌈 紫外可见吸收光谱 | `紫外光谱工具/` | 光谱仪标定、6 种共轭分子的 λmax/ε、一维势箱验证、Voigt 分峰、TD-DFT 对照 |
| 🧴 溶液表面吸附 | `表面吸附工具/` | 最大气泡压力法 + 吊片法测表面张力，Gibbs 吸附求 Γ∞、q、q_c |
| ⏱️ 化学动力学 | `化学动力学工具/` | 数智旋光仪测蔗糖水解，积分法判级数、求 k₁ 与氢离子级数 |
| 💨 液体饱和蒸气压 | `蒸气压工具/` | 动态法测水 + 静态法测环己烷，克氏拟合求 T_b、Δ_vap H_m、Δ_vap S_m，对楚顿规则 |
| ⚡ 电化学（循环伏安法） | `电化学工具/` | CHI 工作站测 N₂/甲醇体系 CV：铂电极活性面积、ORR/MOR 起始电位、DMFC 极化曲线 |
| ⚗️ 双液体系沸点-成分图 | `双液系工具/` | 环己烷-乙醇：折射率-组成工作曲线（二次拟合+离群点剔除）、回流冷凝法测沸点与气液两相组成、相图与最低恒沸点 |
| 🧲 稀溶液法偶极矩 | `偶极矩工具/` | 电容法测正丁醇/环己烷溶液介电常数，Hedestrand 外推求 P̄₂^∞，结合摩尔折射度得 μ |
| 🚪 统一入口 | `物化实验报告工具/` | 一个卡片页，一次拉起全部已安装模块 |

## 快速开始

### 一键入口（推荐）

双击桌面的 **`物化实验报告工具`** 快捷方式，或双击本目录的 **`启动入口.vbs`**，
浏览器会打开 `http://127.0.0.1:8700` 的卡片页，点哪张卡片就进哪个实验的界面。

全程**不会弹出黑色命令行窗口**：入口和八个模块都在后台运行。
再点一次快捷方式不会重复起服务，只是把入口页重新打开。

停止服务（原来的「关掉黑窗口」已经没有窗口可关了）：

- 入口页右上角点 **停止全部服务**；或者
- 双击本目录的 **`停止服务.vbs`**（会把独立启动的模块和 `高斯计算工具` 一起收掉）。

后台看不到界面时，运行输出都写进 `_tools\启动日志.log`。

### 单独启动某个模块

进各自的工具目录双击 **`启动.vbs`**（同样没有黑框），或者在命令行里跑：

```bat
python 燃烧热工具\run.py
python 溶解热工具\run.py
python 紫外光谱工具\run.py     :: 默认 http://127.0.0.1:8791
```

各目录里保留了 `启动.cmd`，它现在只是转去叫 `启动.vbs`，不再开窗口；
想看 Python 版本、依赖安装这些原始输出，直接用上面那行 `python ... run.py`。

## 安装依赖

```bash
python -m pip install -r requirements.txt
```

需要 Python 3.10+（推荐 3.11）。依赖只有 `python-docx`、`numpy`、`scipy`、`matplotlib`、`openpyxl`。
首次运行 `启动.vbs` 时若缺依赖，会自动弹一个命令行窗口装（装完自动关闭），
也可以直接双击 **`安装依赖.cmd`**。

## 各模块做什么

### 燃烧热工具

读课程软件导出的温度–时间数据，雷诺校正取 ΔT，苯甲酸标定 W，计算样品燃烧热
（含点火丝、棉线修正），报告里给表格与燃烧焓对照。支持软件取点 / 手选取点。

### 溶解热工具

累加法测不同 n₀ 下的积分溶解热，拟合经验方程并求微分溶解热、微分冲淡热；
报告含 Q–n₀ 曲线、拟合参数表与讨论。

### 紫外光谱工具

- 用氘灯特征谱线标定 pixel→波长（线性拟合 R² 显示在界面）；
- 6 种共轭分子（A1~A4、B1、B2）的吸收光谱，自动寻峰得 λmax，Beer–Lambert 拟
  合求 ε；
- 一维势箱模型验证、Voigt 分峰（A3）、光源/杂散光校正；
- **高斯计算（TD-DFT）**：可以从同级的 `高斯计算工具` 读取 TD-DFT 结果，
  界面显示「计算 λmax / f」，并把计算–实验对照表自动写进报告 3.5 节。

> TD-DFT 对照需要另一个仓库的 [高斯计算工具](https://github.com/ZhangRuijie66/Chemdraw-To-Gaussian)
> 与本目录同级（`…/物理化学实验/高斯计算工具/`）；没有它时其他功能不受影响。

### 表面吸附工具

两种方法并列：最大气泡压力法（录入左右液柱高度，自动算 Δh、扣除零点）和吊片法
（录入三次表面张力读数）。作 γ–lg c（讲义口径）或 γ–ln c（旧报告口径）图，
选高浓度线性区拟合得 Γ∞、q，并计算浓度修正后的 q_c 与相对偏差。
数据可手工录入，也可从 CSV/TXT 导入；示例数据来自同课程 2025 年报告，仅作演示。

### 化学动力学工具

直接导入 Polariputer 动态测量保存的 xlsx（列 `time` / `angle`），也可以粘贴两列
`t α`。先作旋光度–浓度标定（可剔离群点、画 95% 置信带），再对每组作零级/一级/二级
线性化判定蔗糖级数，给出 k₁、t₁/₂，最后由 k₁–c(H⁺) 非线性拟合与 lg–lg 线性拟合
确定氢离子反应级数。示例数据同样来自 2025 年报告。

### 蒸气压工具

动态法测水（50 kPa → 大气压逐次升压）+ 静态法测环己烷（大气压 → 50 kPa 逐次降压）。
直接导入课程数据处理用的 xlsx/csv（自动按温度骤降切成两支、识别大气压沸点），
对 ln(p/p⊖)–1/T 作线性回归（参数不确定度用 OLS 标准误），求常压沸点
T_b = A/(B−ln(p₁/p⊖))、摩尔蒸发焓 A·R 与摩尔蒸发熵，报告含完整的不确定度推导、
水的「整体温度偏高 1.0 ℃ 复算」对照、两组误差分析与楚顿规则讨论。
示例数据来自 2025 年报告同一批处理表，自检期望值见 `蒸气压工具/README.md`。

### 双液系工具

环己烷-乙醇双液系的沸点-成分图。称量法建立折射率-组成工作曲线
（二次多项式拟合 + 学生化残差离群点剔除），回流冷凝法测定 16 个组成的
沸点与气、液两相折射率，反推组成后绘制相图，用弧长参数化 B 样条定位
最低恒沸点，并做组成的不确定度传播与文献对比。

- 组成变量可切换：**质量比 m₁/m₂**（默认，二次拟合优度最高，R²≈0.9996）
  与**质量分数**（讲义字面口径）；文献恒沸组成一律以乙醇质量分数填写，
  工具会自动换算到同一变量再比较。
- 数据直接在网页表格里改：滴瓶称量数据（m₁/m₂/n）、沸点测定
  （体积、两相折射率平行读数、T、p）；「剔除」勾选框控制工作曲线的离群点。
- 恒沸点定位：气相线/液相线各用一条弧长参数化的三次 B 样条平滑，
  取两条曲线相差最小的位置（相图上两线在恒沸点相切）。

### 偶极矩工具

正丁醇/环己烷溶液：桥法测电容换算介电常数、DE45 密度计测密度（比重瓶对比），
对 ε–x、ρ–x 两条线性拟合（Hedestrand 外推）求总摩尔极化度 P̄₂^∞，
结合摩尔折射度 R 得偶极矩 μ = 12.81√[(P̄₂^∞−R)T]。报告含完整的 A/B/C 不确定度
推导、表 6 置零归因（主要误差来源=电容测量）、电容 0.01 pF 误差假设检验、
实测 vs 外推（S 型曲线）讨论。可直接导入课程数据处理 xlsx；自检期望值见
`偶极矩工具/README.md`。


## 报告输出

点「一键生成报告 (.docx)」，输出到 `…/物理化学实验/实验报告输出/<学号-姓名-实验>/`，
报告和插图在一个文件夹里，直接打包上传即可。报告使用课程模板（封面、中文排版、

## 说明

- `settings.json`（个人姓名/学号/数据目录等）**没有**提交到仓库，首次运行会自动生成，
  点界面右上角「存为默认」即可保存；
- 原始数据目录（`1 燃烧热/`、`2 溶解热/`、`3 紫外光谱搭建/`）与导出报告也不在仓库里；
  表面吸附/化学动力学/蒸气压三个模块的原始数据存在各自的 `data/*.json`，同样不提交；
- 每个模块都是独立进程、独立 `pcal` 包，入口只负责挑端口、拉起子进程、做健康检查、
  退出时收摊；
- 后台进程按命令行精确回收：`停止服务.vbs` 只杀命令行里带
  `<某个工具>\run.py` 的 python，不会误伤别的程序。
